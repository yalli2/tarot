# 아르카나 78 · HR 인사이트 랩

교재: *The Big Book of Tarot Meanings* (Sam Magdaleno). 사이트의 한국어 해설은 학습용으로 요약·재구성한 것이며 원문이 아닙니다.

## 실시간 공유 켜기 (선택)
GitHub Pages는 정적 호스팅이라 서버가 없습니다. 수강생끼리 결과를 보려면 무료 Firebase Realtime Database를 연결하세요.

1. Firebase 콘솔에서 프로젝트 생성 → **Realtime Database** 만들기
2. **규칙** 탭에 `database.rules.json` 내용을 붙여넣기 (읽기 공개, 쓰기는 새 글 작성만 허용)
3. 데이터베이스 주소(`https://…firebasedatabase.app`)를 `config.js`의 `firebaseUrl`에 입력
4. 수업마다 **세션 코드**(예: `hr-2026-1반`)를 안내하면 같은 코드를 쓰는 사람끼리 결과가 모입니다.

비워 두면 로컬 모드로 동작합니다(해당 브라우저 안에서만 보임). 닉네임은 실명을 쓰지 않도록 안내하세요.

## 배포
저장소 Settings → Pages → Branch: `main` / root. 빌드 과정 없이 정적 파일 그대로 동작합니다.

## 이용 원칙
성찰·코칭 도구입니다. 예측, 진단, 채용·평가 등 인사 결정의 근거로 사용하지 않습니다.

## 카드 이미지 출처
Pamela Colman Smith의 *Rider-Waite-Smith Tarot*(1909) — 퍼블릭 도메인. 스캔 이미지는 [steve-p.org](https://steve-p.org/cards/RWSa.html)에서 정리한 [mixvlad/TarotCards](https://github.com/mixvlad/TarotCards)를 사이트용(360×600)으로 줄여 사용했습니다. 교재(Sam Magdaleno)의 삽화는 사용하지 않았습니다.
